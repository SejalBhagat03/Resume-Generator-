# 📄 Resume Generator: Project Guide & Workflow

This project is a **programmatic resume builder** designed to compile a beautifully formatted, single-page, ATS-friendly resume PDF from structured data.

## 💡 Why I Built This (My Inspiration)

As a student, I faced numerous challenges when building and updating my resume in standard word processors. I don't have Microsoft Office installed on my laptop because it is too costly, and formatting a perfect, single-page professional resume in free alternative editors often resulted in frustrating layout shifts and broken margins.

To solve this problem permanently, I built this **data-driven resume generator**. Instead of dealing with frustrating visual formatting, I can now compile a pixel-perfect, ATS-compliant resume instantly—**simply by adding my details to a structured JSON file!**

## 💎 Pro Features Pack

To make this project stand out in technical interviews and serve as a robust showcase, we've implemented four advanced software engineering features:

### 1. 🎨 Dynamic Design Customizer
*   **Live Styling:** Change primary accent colors (Blue, Green, Red, Purple, Slate, or Custom), page margins (12pt to 32pt), and typography scaling (0.8x to 1.2x) directly in the sidebar.
*   **Single-Page Fit Solver:** If your content runs slightly over the 1-page limit, you can slide the Font Scale down (e.g. `0.95x`) to automatically compress vertical spacing and keep the resume on a single page.

### 2. 📊 Offline ATS Compliance Scanner
*   **Zero API Limits:** Run a robust, local heuristic compliance audit on your resume data. 
*   **Key Checks:** Contact details presence, social link completeness, core section names check, and **Action Verbs Density Check** (analyzes your bullet points for strong industry verbs like *Engineered, Optimized, Developed*).
*   **Scorecard:** Outputs a visual score out of 100 with actionable feedback to optimize readability.

### 3. 💻 Web Portfolio Website Exporter (index.html)
*   **Single Source of Truth:** Generate both a PDF and a beautiful personal website from the exact same JSON data.
*   **Clean Output:** Under the "Export Web Portfolio" tab, click to download a self-contained, responsive HTML portfolio (`index.html`) using premium dark-slate styling and matching your custom accent color. 
*   **Instant Host:** You can drag-and-drop this file into a GitHub repository named `username.github.io` to host it online for free in 1 click!

### 4. 🚀 Cloud CI/CD Automation (GitHub Actions)
*   **Pipeline:** Located in `.github/workflows/compile_resume.yml`.
*   **Auto-Build:** Whenever you commit and push updates to `resume.json` to GitHub, a runner virtual machine automatically executes the Python engine to rebuild the PDF and commits it back to your repository. This ensures your resume is always up-to-date in the cloud.

## 🔄 How to Run the Project

You can run this project in two ways: through the **No-Code Web Workspace** (recommended for styling and analysis) or the **Local Batch Script** (fastest for raw updates).

### Method A: No-Code Web Interface
1. Install dependencies (only needed once):
   ```bash
   pip install -r requirements.txt
   ```
2. Start the web app interface:
   ```bash
   python -m streamlit run app.py
   ```
3. A browser window will open automatically at `http://localhost:8501`.
   * **Edit Info:** Fill in the forms or edit the raw JSON directly in the tabs.
   * **ATS Scan:** Go to the "ATS Compliance Check" tab to view your score.
   * **Custom Design:** Modify color themes, margins, and font scaling in the sidebar.
   * **Export Portfolio:** Download your personalized portfolio web page (`index.html`).
   * **Download PDF:** Click "Compile & Preview PDF" to see the live page preview and download your single-page PDF!

### Method B: Local Command Line / Batch File
If you just want to compile the local `resume.json` directly to a PDF:
* **Double-click `run.bat`** in your file explorer.
* Or, run this in your terminal:
  ```powershell
  python generate_resume.py
  ```
This instantly generates the PDF and opens it in your default viewer.

## 🚀 Deploying the Web App Online (Host for FREE)

You can share your interactive resume generator with the world so that others can use it:

1. **Push your code to GitHub:** Ensure your workspace folder is committed and pushed to a repository on your GitHub account.
2. **Sign up at Streamlit:** Log into [share.streamlit.io](https://share.streamlit.io/) with your GitHub account.
3. **Deploy:** Click **"Create app"**, select your repository, select your branch (e.g., `main`), set the Main File Path to `app.py`, and click **"Deploy!"**

Within 2 minutes, your app will be live at a public URL (e.g. `https://yourname-resume.streamlit.app/`), where other people can input their information and download their customized resume!
